# Introduction to Vim

## Watch the slideshow

Open the [presentation](https://etuardu.github.io/vim-intro-talk/) in your browser.

No installation or download is required.

## Try the demos

Clone this repository and move to the demos folder:

```bash
git clone https://github.com/etuardu/vim-intro-talk.git
cd vim-intro-talk/demos/
```

Open a demo file in Vim and try to solve the task:

```bash
vim intro.js
```

The repository includes everything you need to follow along, including the supporting assets.
